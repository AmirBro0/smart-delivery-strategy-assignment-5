Assignment 5 — Smart Delivery and Route Optimization Engine

ГОТОВО
Java-проект с пятью стратегиями, восемью маршрутами, автоматическим выбором
стратегии, тремя переключениями во время работы, проверкой ограничений и
объяснениями решений. Пройден 51 JUnit 5 тест.

БЫСТРЫЙ ЗАПУСК
Откройте терминал в этой папке. Требуется Java 17 или новее:
    java -jar dist/smart-delivery.jar

Отдельные режимы:
    java -jar dist/smart-delivery.jar --compare
    java -jar dist/smart-delivery.jar --switch
    java -jar dist/smart-delivery.jar --auto
    java -jar dist/smart-delivery.jar --failures

СБОРКА И ТЕСТЫ
Требуется полный JDK 17+ с java, javac, jar:
    powershell -ExecutionPolicy Bypass -File .\build.ps1 -Run
Либо при установленном Maven:
    mvn package
    java -jar target/smart-delivery.jar

Первый запуск тестов скачивает JUnit из Maven Central. Само приложение
не требует сети. Для сборки без тестов: build.ps1 -SkipTests.
